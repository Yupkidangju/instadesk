# 감사 5 수정 계약 (초안)

작성일: 2026-11-17 (Asia/Seoul). 원본 `docs/audit/audit_report_5.md`와 이전 감사 보고서는 수정하지 않는다.

## 목표와 범위

`IMP-F010`, `IMP-F011`, `DBG-F014`, `DBG-F015`, `DBG-F016`, `SEC-F008`을 현재 2.1.2 문서·코드·테스트와 대조한다. 터미널/작업 영역 휠 경계와 기록 수명을 먼저 고정하고, 설치 패키지에 동봉되는 Linux 안내와 Windows/Linux SHA-256 절차를 맞춘다. 별도 코드 서명·자동 업데이트·ASAR/Fuses 도입은 이 수정에 포함하지 않고 배포 위험/검토 조건으로 남긴다.

## 동작 계약

```text
작업 영역(여러 VM 타일, 세로 스크롤)
└─ 타일
   ├─ TERM: xterm 기록 스크롤
   ├─ DESKTOP: 원격 뷰/기존 Alt+휠 정책
   └─ EXEC/LOGS/PROCS: 각 패널 자체 스크롤
```

1. **휠 소유:** 포인터가 xterm 안에 있으면 일반 휠/트랙패드 델타는 터미널 기록에만 적용한다. 기록의 위·아래 끝에서도 같은 입력을 작업 영역으로 연쇄 전달하지 않는다. 터미널 위 `Shift+휠`은 터미널 기록을 움직이지 않고 작업 영역을 스크롤한다. 타일 헤더·간격·작업 영역 위 일반 휠은 작업 영역을 스크롤한다. Desktop은 기존 계약대로 작업 영역이 길면 일반 휠은 타일, `Alt+휠`은 원격 화면에 보낸다. 390/768/1280px과 1×1/2열에서 같은 규칙을 유지한다.
2. **터미널 기록:** 같은 타일·세션(`main`/`agent`/`aux`)에서 1×1 포커스와 TERM↔다른 탭·SPLIT 왕복 중 xterm 출력과 아래에서 읽던 줄 간격을 메모리에 보존한다. 숨김 시 앱 소유 PTY를 닫고 돌아올 때 새 티켓으로 재접속한다. 기록은 최근 1000 scrollback 줄로 제한하고, 직렬화된 항목은 최대 256KiB, 전체 메모리 캐시는 최대 2MiB/16항목의 LRU다. 큰 항목/축출된 항목은 복원되지 않을 수 있다. 원격 서버의 최근 출력 재전송이 복원 기록 끝에 반복될 수 있음을 명시한다.
3. **정리 경계:** 타일 닫기·프로필 삭제·볼트 잠금·앱 종료 때 해당 실 프로필 기록을 지운다. 앱 재실행 후 디스크에 터미널 기록을 복원하지 않는다. 사용자가 Clear를 누른 기록은 보존하지 않는다. EXEC의 스트림 요청은 탭 이탈 시 중단하고 출력/입력 초안은 폐기한다. 이미 서버에 전달된 명령 자체의 원격 중단은 보장하지 않는다. LOGS/PROCS는 방문할 때 다시 조회한다. 이 범위를 UI/README에 짧게 알린다.
4. **설치·해시:** Linux 동봉 안내의 파일명은 패키저가 현행 버전·아키텍처에서 생성한다. 안내에 적힌 아카이브와 동일한 릴리스의 `SHA256SUMS.txt`를 다운로드해 **설치 전** 정확한 파일명을 검증한다. Windows는 PowerShell `Get-FileHash`, Linux는 `sha256sum -c` 예제를 제공한다. 체크섬은 동일 릴리스 자산의 손상/변경 탐지이지 게시자 서명은 아니다. CI는 두 Linux 아키텍처의 동봉 안내 이름·메인 실행 파일 비-SUID·sandbox helper SUID를 확인한다.
5. **Desktop 안내:** 좁은 폭에서도 원격 화면/작업 영역 휠 단축키를 발견할 수 있게 상단 패널 안내를 노출한다. 실제 복수 네이티브 뷰 휠은 별도 수용 조건으로 남긴다.

## 구현 순서와 검증

1. `spec.md`, `designs.md`, 결정·설치 문서를 이 계약으로 갱신한다.
2. 휠 끝 경계, Shift+휠, 포커스/탭 왕복 기록·스크롤, 잠금/삭제 정리, 동봉 설치 안내 버전의 실패 회귀를 추가한다.
3. 휠 소유 CSS/핸들러, 제한 메모리 기록 복원, 안내 생성/패키지 CI를 구현한다.
4. 관련 브라우저/네이티브 스크롤, 타입, 전체 테스트, 빌드·의존성 감사, 배포 자산 검증 결과를 finding ID별 별도 기록에 남긴다. 실행하지 못한 실 경로를 PASS로 표기하지 않는다.
