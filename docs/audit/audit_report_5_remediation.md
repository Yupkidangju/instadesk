## 계약과 범위

[감사 5 수정 계약](../electron/audit_5_remediation.md)을 `spec.md`, `designs.md`, `DESIGN_DECISIONS.md`에 코드보다 먼저 반영했다. 터미널 일반 휠은 xterm 전용, `Shift+휠`은 작업 영역 전용이다. 타일·세션별 최근 기록과 읽던 위치는 메모리 한도 안에서 포커스·탭 왕복 동안 복원하고 숨긴 PTY는 닫는다. 잠금·타일 닫기·프로필 삭제에는 기록을 지운다. EXEC는 탭 이탈 때 로컬 스트림과 출력을 정리하지만 서버에 이미 제출한 명령의 원격 중단은 보장하지 않는다.

## 실제 브라우저 재현과 수정 후 실측

키가 없는 로컬 데모에서 Chromium과 Vite를 사용했다. 휠 경계 재현은 4타일 2열로도 여러 행 스크롤이 생겨 가능했다. 이 검사는 실제 PTY 서버 연결이 아니다.

| 경로 | 입력 전 | 입력 후 | 판정 |
| --- | --- | --- | --- |
| 개발 브라우저 수정 전, 터미널 끝 근처 | 작업 영역 `200`, 첫 터미널 `386/486` | 휠 `+200`: 작업 영역 `400`, 터미널 `486` | 한 입력이 두 영역을 움직이는 결함 재현 |
| 개발 브라우저 수정 후 | 작업 영역 `200`, 첫 터미널 `458/558` | 휠 `+200`: 작업 영역 `200`, 터미널 `558` | 경계 연쇄 이동 차단 |
| 개발 브라우저 Shift+휠 | 작업 영역 `200`, 터미널 `558` | 작업 영역 `400`, 터미널 `558` | 명시적 작업 영역 이동 |
| 생산 빌드 1280px | 작업 영역 `200`, 터미널 `386/486` | 휠 `+200`: `200`, `486`; Shift+휠 후 `400`, `486` | 통과 |
| 생산 빌드 390px | 작업 영역 `100`, 터미널 `1052/1152` | 휠 `+200`: `100`, `1152`; Shift+휠 후 `300`, `1152` | 통과 |
| 생산 빌드 768px | 작업 영역 `100`, 터미널 `476/576` | 휠 `+200`: `100`, `576`; 끝에서 `+15`도 작업 영역 `100` 유지 | 통과 |

생산 빌드 1×1에서 첫 터미널에 데모 명령 25회를 넣고 스크롤 위치를 `200`으로 두었다. 다른 타일로 포커스 이동 후 복귀 시 `scrollHeight 1006→1024`, `scrollTop 200→198`; TERM→EXEC→TERM 후 `1042/198`로 기록과 읽던 위치가 유지됐다. 생산 빌드 브라우저 콘솔 오류는 0건이었다. 개발 서버에서는 React StrictMode 재마운트 때 xterm 내부 예약 작업의 `dimensions` 오류가 관찰됐지만 생산 빌드에서는 재현되지 않았다. 처음 추가한 `cols/rows=undefined` 오류는 브라우저에서 발견해 기본 크기 보정과 테스트를 추가했고, 미완성 복원 쓰기가 캐시를 덮는 경계도 재현·수정했다.
