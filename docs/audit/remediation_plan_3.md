# Audit 3 수정 계획

2026-11-01 · 대상: `audit_report_3.md`의 IMP-F004/005/006, DBG-F008/009/010, SEC-F001 잔여 사항, SEC-F004. 기존 audit 1~3 보고서와 감사 3의 이미지 증거를 보존한다. 사용자가 추가 요청한 터미널·스트림 분할 조절도 같은 UI 변경에 포함한다.

1. 실제 볼트 저장 스키마와 보안 표현을 문서에 맞춘다. 최소 지원 폭은 390 CSS px로 정한다. 1024px 미만에서는 노드 목록을 닫을 수 있는 서랍으로, 1280px 미만에서는 타일을 한 열로 표시한다. 단일 타일은 항상 전폭을 사용한다.
2. 한 VM 타일에 터미널과 데스크톱을 함께 보는 SPLIT 화면을 추가한다. 768px 이상에서는 좌우 경계를 포인터와 키보드로 25~75% 범위에서 조절한다. 더 좁은 폭에서는 상하 분할로 전환한다. 데스크톱 뷰어는 알려진 원본 해상도에 맞춰 비율을 유지하며 가용 영역에 맞게 크기를 조절한다.
3. 신뢰 프록시 origin은 REST/SSE와 티켓에 `/instabox-api`, API 호스트 PTY에 `/instabox-api`, Connect 호스트 PTY에 `/instabox-connect` 접두사를 사용한다. 프록시 운영자는 두 업스트림을 각각 중계해야 한다. 허가된 실제 티켓 검증은 별도 게이트다.
4. 머신 갱신은 프로필별 성공·실패를 분리하고 성공한 현재 결과와 데모만 반영한다. 늦게 끝난 이전 갱신은 최신 상태를 덮지 않는다.
5. 프로필 삭제는 잠금 해제 후 이름·ID를 보여주는 확인 단계를 거친다. 삭제는 로컬 암호화 키에 대해 되돌릴 수 없다. 삭제 대상의 요청·소켓·타일·출력만 종료하며 다른 프로필의 연결은 유지한다. 볼트 잠금은 Broadcast 실행을 중단하고 명령·출력을 지운다.
6. 위 경계의 회귀 테스트와 390/768/1280px 브라우저 확인, `npm ci`, 타입 검사, 테스트, 빌드, 의존성 감사, 로컬 preview 결과를 후속 수정 검증 문서에 기록한다. Pages 배포는 사용자가 직접 시도하기로 한 이전 지시를 유지한다. 허가된 실 키·운영 프록시가 없어 실제 API 경로는 HOLD로 남긴다.
