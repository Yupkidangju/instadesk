# Audit 1 수정 계획

2026-11-01. 범위: `audit_report_1.md`의 IMP, DBG, SEC 지적 사항과 연결된 XPF 충돌. 원본 보고서는 보존한다. 이 문서는 구현 전 계약과 검증 순서를 기록한다.

1. `spec.md`, `DESIGN_DECISIONS.md`, `BUILD_GUIDE.md`에 정적 배포, 신뢰 프록시, 잠금, 세션 계수 계약을 먼저 명시한다. 확장 프로그램의 광역 CORS 규칙은 비활성화한다.
2. 볼트 잠금 시 앱 소유 채널과 요청을 끝내고 출력/서명 링크를 제거한다. PTY 연결 예약과 실제 연결을 계수하며 재연결을 명시적으로 수행한다.
3. 머신 페이지네이션, SSE 경계/종료, 생성 대상 기본값, 프록시 입력 검증을 수정한다.
4. Git 무시 정책, Pages Actions 빌드, 라이선스와 공개 저장소를 준비한다. 의존성은 호환성을 확인해 잠금 파일과 함께 갱신한다.
5. finding별 회귀 테스트, `npm ci`, 전체 테스트, 타입 검사, 빌드, npm audit, 빌드 자산 경로 확인 후 `audit_report_2.md`에 증거와 남은 HOLD 조건을 기록한다. 최종 Pages URL과 허가된 실 API 검증은 사용자 측 Pages 설정 이후 별도 수행한다.

미확정: 최종 Pages URL, 실 서비스의 CORS/티켓/iframe 정책 및 허가된 테스트 키. 로컬 코드 검증만으로 실 서비스 PASS를 선언하지 않는다.
