# InstaDesk 2.1.3

## Changes

- Keep terminal wheel input inside terminal history at its scroll limit. Shift+wheel scrolls the VM workspace deliberately.
- Restore recent terminal output and the reading position after changing tile focus or tabs, within a bounded in-memory cache. Hidden PTY connections close and reconnect on return.
- Generate the Linux installation guide with the archive's actual version and architecture, and add Windows/Linux SHA-256 checks before installation.
- Show the Desktop wheel hint on smaller screens.

## 변경 사항

- 터미널 기록 끝에서 휠 입력이 작업 영역까지 이동하던 문제를 막았습니다. Shift+휠로 VM 작업 영역을 스크롤할 수 있습니다.
- 타일 포커스나 탭을 바꿨다 돌아오면 최근 터미널 출력과 읽던 위치를 제한된 메모리에서 복원합니다. 숨긴 PTY는 닫았다가 돌아올 때 재연결합니다.
- Linux 동봉 설치 안내에 실제 아카이브 버전·아키텍처를 넣고 Windows/Linux 설치 전 SHA-256 확인 절차를 추가했습니다.
- 좁은 화면에서도 Desktop 휠 안내가 보이게 했습니다.
