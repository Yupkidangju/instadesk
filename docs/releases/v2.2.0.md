# InstaDesk 2.2.0

## Changes

- Open multiple PTY sessions (`main`, `agent`, `aux`) for the same VM as separate workspace tiles while preventing duplicate session connections and isolating per-tile native Desktop views (`desktop_${tileId}`).
- Add a global session status indicator strip and per-tile traffic-light headers (`RUN` / `PROMPT` / `IDLE` / `OFF`) for shell and AI agent prompts, with inline quick-reply actions (`Y`, `N`, `Enter`, `1`, `2`, `Esc`, `Ctrl+C`).
- Add synchronized live PTY command dispatch (`ALL`, `SYNCED`, `PROMPTS`), keystroke mirroring across synced tiles (automatically paused on sensitive password/passphrase prompts and reset on lock), batch tile actions, and local workspace layout presets (`instabox_deck_presets_v1`).
- Show master passphrase creation (`CREATE VAULT`) when the vault is uninitialized and unlock (`UNLOCK VAULT`) when configured; automatically erase stored vault data after 10 failed unlock attempts.

## 변경 사항

- 동일 VM의 여러 PTY 세션(`main`, `agent`, `aux`)을 별도 타일로 동시에 열 수 있게 하고, 중복 세션 전환을 기존 타일 포커스로 수렴시키며 타일별 네이티브 Desktop 뷰(`desktop_${tileId}`)를 격리했습니다.
- 쉘·AI 에이전트 프롬프트를 감지하는 상단 통합 세션 상태 인디케이터 바와 타일별 신호등 배지(`RUN` 🔴 / `PROMPT` 🟡 / `IDLE` 🟢 / `OFF` ⚪), 인라인 빠른 응답(`Y`, `N`, `Enter`, `1`, `2`, `Esc`, `Ctrl+C`)을 추가했습니다.
- 라이브 PTY 동시 명령 전송(`ALL`, `SYNCED`, `PROMPTS`), 동기화 그룹 키스트로크 미러링(암호 프롬프트 자동 일시 차단 및 잠금 시 해제), 일괄 제어, 비밀정보 없는 로컬 워크스페이스 프리셋 저장·복원을 추가했습니다.
- 초기 미설정 볼트 해제 시 생성(`CREATE VAULT`) 흐름을 제공하고, 기설정 볼트 잠금 해제 시 10회 이상 실패하면 저장된 볼트 데이터를 자동 삭제하도록 변경했습니다.
