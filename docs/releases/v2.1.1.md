# InstaDesk 2.1.1

## Changes

- Lock the vault after 15 minutes without user input. Background refresh no longer extends the timer.
- Mark a PTY live only after the server confirms its session. Show failure categories and retry transient connection failures up to three times.
- Keep encrypted key profiles in a version-independent app data location, and prevent background refresh from overwriting a newly saved profile.
- Upgrade legacy vaults to a stronger key-derivation setting when unlocked. Require a passphrase of at least 15 characters for new vaults and passphrase changes.
- Explain in the app that Broadcast sends independent commands to running VMs and does not need open PTY terminals.

## 변경 사항

- 사용자 입력이 15분간 없으면 볼트를 잠급니다. 자동 새로고침은 잠금 시간을 연장하지 않습니다.
- 서버가 세션을 확인한 뒤에만 PTY를 연결 완료로 표시합니다. 실패 종류를 보여 주고 일시적인 연결 오류만 최대 세 번 재시도합니다.
- 버전이 바뀌어도 같은 앱 데이터 위치에서 암호화된 키 프로필을 읽고, 자동 조회가 새로 저장한 프로필을 덮는 문제를 수정했습니다.
- 기존 볼트를 잠금 해제할 때 키 파생 설정을 강화합니다. 새 볼트와 암호문구 변경에는 최소 15자를 요구합니다.
- Broadcast가 PTY 연결 없이 실행 중 VM에 개별 명령을 보낸다는 점을 앱에 명시했습니다.
