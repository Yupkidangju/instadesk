# InstaDesk 2.1.1

Windows x64, Linux x64, Linux arm64용 Electron 앱입니다. 동일 OS 사용자 데이터 경로에 남아 있는 기존 `app://instadesk` 암호화 프로필은 버전 교체 후에도 마스터 암호로 잠금 해제할 수 있습니다. 예상한 프로필이 보이지 않으면 새 볼트를 초기화하기 전에 사용자 계정과 저장 위치를 확인하세요.

- 사람의 입력이 없는 15분 뒤 자동 잠금합니다. 자동 목록 조회는 잠금을 연장하지 않습니다.
- PTY는 서버 `session` 신호 후 LIVE가 되며, 401/403·409·429·503·`taken` 및 종료 코드를 구별합니다. 429/503/일시 네트워크 오류만 최대 3회 제한 재시도합니다.
- 새 볼트는 PBKDF2-HMAC-SHA256 600,000회와 최소 15자 마스터 암호문구를 사용합니다. 기존 v1 볼트는 정상 잠금 해제 때 프로필을 보존하며 v2로 이행합니다. 기존 암호가 짧았다면 KEY VAULT에서 긴 암호문구로 변경하세요. API 키의 원격 회전은 별개입니다.
- Broadcast는 열린 PTY 없이도 실행 중 VM별 독립 SSE `exec` 요청을 보냅니다.
- 볼트 사용자 데이터 경로는 버전과 실행 폴더에 관계없이 고정됩니다. 자동 조회와 새 키 저장이 겹칠 때 프로필이 덮이는 경합을 수정했습니다. 기존 저장소가 보이지 않으면 새 볼트를 초기화하기 전에 OS 사용자 계정과 실행 경로를 확인하세요.

세 아카이브와 `SHA256SUMS.txt`는 세 네이티브 CI 패키지/로드 게이트 뒤 게시됩니다. Linux 설치는 [2.1.0과 동일한 sandbox helper 조건](../../BUILD_GUIDE.md)을 따릅니다. 코드 서명·자동 업데이트·물리 ARM 및 다른 Linux 배포판은 검증 대상 밖입니다. 감사 4 finding별 결과와 실 5대 확인 범위는 `docs/audit/audit_report_4_remediation.md`에 기록합니다.

이번 검증에서 사용자가 보고한 새 API 키 프로필 5개는 접근 가능한 기존 저장 기록에서 찾지 못했습니다. 자동 조회가 새 프로필을 덮을 수 있었던 경합은 재현·수정했지만, 그 5개가 사라진 직접 원인이나 복구는 확인되지 않았습니다. 실제 5대 PTY/SSE 연결은 사용자 직접 수용 검사로 남겨 둡니다.
