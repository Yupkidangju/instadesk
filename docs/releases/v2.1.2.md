# InstaDesk 2.1.2

## Changes

- Fix a Desktop view that could remain over the right column while scrolling a two-column workspace with five or more VMs. The view now follows its tile and hides outside the workspace without reconnecting.
- When the VM grid scrolls, the wheel over a Desktop view moves the VM tiles. Use Alt+wheel for scrolling inside the remote Desktop.

## 변경 사항

- VM 5대 이상을 2열로 열고 스크롤할 때 오른쪽 Desktop 화면이 제자리에 남는 문제를 수정했습니다. 뷰가 타일을 따라 이동하며 작업 영역 밖에서는 연결을 유지한 채 숨겨집니다.
- VM 그리드가 스크롤될 때 Desktop 위의 일반 휠은 타일을 움직입니다. 원격 Desktop 내부 스크롤에는 Alt+휠을 사용합니다.
