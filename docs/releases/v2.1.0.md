# InstaDesk 2.1.0

Windows x64와 Linux x64·arm64용 Electron 앱입니다. Windows ZIP은 압축 해제해 `InstaDesk.exe`를 실행합니다. Linux는 아래 sandbox helper 설치 후 일반 사용자로 `InstaDesk`를 실행합니다. GitHub Pages와 Cloudflare Worker는 필요하지 않습니다.

- 세 아키텍처는 각 네이티브 GitHub runner에서 빌드·패키징·가상 화면 로드 스모크를 통과한 뒤 게시됩니다.
- Windows x64에서 실 InstaBox 키의 VM 목록, PTY, Desktop 영상과 SPLIT 화면비 맞춤을 확인했습니다.
- API 키는 앱 로컬 볼트에 암호화 저장되고 마스터 암호는 저장하지 않습니다. 이전 Pages 볼트는 자동 이전되지 않습니다.
- `SHA256SUMS.txt`로 다운로드한 아카이브를 확인할 수 있습니다.

## Linux 설치 (x64 또는 arm64 네이티브 환경)

```bash
name="InstaDesk-2.1.0-linux-$(uname -m | sed 's/x86_64/x64/; s/aarch64/arm64/')"
grep "${name}.tar.gz" SHA256SUMS.txt | sha256sum -c -
sudo install -d -m 0755 /opt/instadesk
sudo tar -xzf "${name}.tar.gz" -C /opt/instadesk
sudo chown -R root:root "/opt/instadesk/${name}"
sudo chmod 4755 "/opt/instadesk/${name}/chrome-sandbox"
"/opt/instadesk/${name}/InstaDesk"
```

`/opt/instadesk`가 `nosuid` 마운트이면 sandbox helper가 동작하지 않습니다. 코드 서명 없는 아카이브를 설치하기 전에 GitHub Release의 SHA-256을 확인하세요. `--no-sandbox`로 실행하지 마세요.

**검증 범위:** Linux ARM64는 네이티브 CI의 가상 화면에서 검증하며 물리 ARM 기기, 다른 Linux 배포판, 코드 서명·자동 업데이트는 확인하지 않았습니다. 실 API 변경·SSE와 Desktop 입력 제어는 별도 검증 대상입니다. API 키가 터미널이나 화면 캡처에 노출되었다면 InstaBox에서 폐기하고 새 키로 교체하세요.
