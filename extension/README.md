# InstaBox Deck inactive bridge reference (Manifest V3)

This directory is retained for reference only. The global CORS rewrite rule is disabled because it affected unrelated websites. Installing the extension does not provide API access. See `../BUILD_GUIDE.md` for the supported connectivity requirements.

## Installation in Chrome / Brave / Edge

1. Open your browser and navigate to `chrome://extensions/` (or `edge://extensions/` / `brave://extensions/`).
2. Toggle on **Developer mode** in the top right corner.
3. Click **Load unpacked** in the top left.
4. Select this `extension` folder.
5. No InstaBox request rules are enabled.
